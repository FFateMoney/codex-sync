授权本机 .codex 文件夹

你需要在系统文件选择器中明确选择目录。此步骤只读取 state_5.sqlite 以建立本地对话列表，不上传聊天内容。

1在系统选择器中打开你的 Codex 配置目录。
2确认授权后读取本地线程标题与会话数量。
3进入控制台，筛选和查看本地对话。
尚未授权本地文件夹。

查找目录

macOS / Linux 通常使用以下默认位置。设置过 CODEX_HOME 时请以其为准。

printf '%s\n' "${CODEX_HOME:-$HOME/.codex}"
macOS 快捷方式文件选择器按 ⌘⇧G，可直接前往目录。
隐藏文件若未显示 .codex，按 ⌘⇧.。
