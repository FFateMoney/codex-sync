授权本机 Codex 文件夹

点击后，请在系统选择器中选择 .codex 文件夹。网页只会在你选择后读取该目录；本页不会上传任何文件。

尚未授权本地文件夹。

常用位置：macOS / Linux 通常为 ~/.codex。如果你设置过 CODEX_HOME，请以它为准。

printf '%s\n' "${CODEX_HOME:-$HOME/.codex}"

在终端运行此命令会显示应在文件选择器中打开的目录。macOS 中按 ⌘⇧G 可直接前往该位置；若看不到隐藏文件，按 ⌘⇧.。

推荐 Chrome 或 Edge。首次使用时可能需要在文件选择器中显示隐藏文件（macOS：⌘⇧.）。
